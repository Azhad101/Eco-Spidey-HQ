Eco-Spidey HQ
Eco-Spidey HQ is a simple civic issue reporting platform designed to help citizens report and track environmental problems around Delhi.

The idea is simple:
See a problem → Report it → Track it → Help solve it.

Features:
Live Civic Map
Report Issues
Track Status
Upvote Issues
Authority Analytics
Hero Board
  A fun leaderboard showing citizens making an impact.

Purpose
The goal of Eco-Spidey HQ is to make reporting local environmental problems simple, interactive, and engaging.
Instead of just reporting a problem and forgetting about it, users can follow its progress and see the impact being made.

Built With
* HTML
* CSS
* JavaScript
* Interactive maps
* Browser-based storage
* GitHub Pages

How It Works
1. A citizen finds a civic problem.
2. They take a photo and submit a report.
3. The issue appears on the map.
4. Other citizens can upvote it.
5. The issue status can be tracked.
6. Once resolved, the issue is marked as **Resolved**.

Why "Eco-Spidey"?
Because being a hero isn't always about saving the world.
Sometimes it's about taking responsibility for your own neighborhood.
With great power comes great responsibility.
